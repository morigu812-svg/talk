# Talk

招待リンクで参加できるブラウザの1対1音声通話です。

1. ホストが「部屋を作る」を押し、マイクを許可します。
2. 招待リンクを相手に送ります。ホスト側のページは開いたままにします。
3. 相手がリンクを開いて「通話に参加」を押し、マイクを許可します。

## 起動・公開

静的サイトなのでビルドは不要です。ローカルでは、このフォルダで
`python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。
公開環境には HTTPS が必要です。GitHub Pages では **Settings → Pages** で
**Deploy from a branch** を選び、対象ブランチの **/(root)** を指定します。

## 接続方式

接続の仲介には PeerJS Cloud を利用し、音声は WebRTC でブラウザ間を直接流れます。
TURN リレーを設定していないため、企業ネットワークなど一部の環境では
直接接続できない場合があります。リンクを知っている人が参加できるため、
招待リンクは通話したい相手にだけ共有してください。
